# Enemy robot sprites

Reference art generated for robot enemy redesign. In-game enemies currently use procedural Pixi vector robots (same thick-outline style as the player tank) so they scale cleanly and face the player.

PNG files here can replace the vectors later once backgrounds are keyed out and sizes are trimmed for Atlas packing.
